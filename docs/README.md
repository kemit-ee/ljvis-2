# LJVIS2 dokumentatsioon

Leidke juhendid ja tehnilised dokumendid [sisukorrast](SUMMARY.md).

- [Kasutusjuhend](user-guide/01-sissejuhatus.md) kirjeldab ametniku ja ettevõtja esindaja toiminguid.
- [Administraatori juhend](admin-guide/01-sissejuhatus.md) kirjeldab kasutajate, õiguste, seadistuse ja andmete haldamist.
- [Andmehalduse juhend](andmehaldus/README.md) kirjeldab klassifikaatoreid, õigusi ja asutuste algandmeid.
- [Töödokumendid](workingdocs/README.md) sisaldavad tehnilisi kirjeldusi ja arendusotsuseid.

## Keel ja terminid

Kasutus-, administraatori- ja andmehalduse juhendid on eesti keeles. Tehnilised
kirjeldused võivad olla eesti või inglise keeles. Järgige toimetamisel
[projekti keelereegleid](../AGENTS.md#tehnilise-dokumentatsiooni-keel).

Kirjutage lühikesed ja üheselt mõistetavad laused. Esitage eeltingimus enne
tegevust. Kasutage sama mõiste kohta sama terminit. Säilitage tehnilised
identifikaatorid, API väärtused, failinimed, koodinäited ja logisõnumid.

Keeletoimetuse leiud ja kontrolli ulatus on [16.10.2026 ülevaates](quality/2026-10-16-keeletoimetus.md).

## Juhendite avaldamine

Juhendite lähtefailid asuvad selles hoidlas. Muutke esmalt lähtefaile ja esitage
muudatused GitHubi tõmbetaotluses. Seejärel uuendage Confluence’i koopiad samade
lähtefailide põhjal. Avaldamise juhised on [kuvatõmmiste juhendis](screenshots/README.md#confluencei-publitseerimine).
